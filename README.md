# Shopping_system_LVGL8

**一个基于 GD32H7XX + LVGL8 的嵌入式购物系统课程项目。**

## 概述

模拟超市收银机软件，运行在 GD32H7XX 开发板上，使用 LVGL 图形库构建触摸屏界面。支持商品选购、优惠结算、交易记录管理、价格与优惠券管理等完整购物流程。

## 基本功能

> 1. 预设 6 种商品（苹果、牛奶、面包、西瓜、可乐、巧克力）及单价；
> 2. 用户点击商品卡片，通过数字键盘输入数量/重量；
> 3. 自动计算总价并实时显示购物车明细；
> 4. 支持 4 种优惠活动（满20减5、9折、满100打8折、满200减50）；
> 5. 购物车实时显示折前合计；
> 6. 结算时自动应用最优优惠并显示折后价格；
> 7. 交易记录保存至 SD 卡（CSV 格式），支持查看历史交易明细。

## 扩展功能

> 1. **优惠券管理** — 可增减每种优惠券数量，支持一键重置为默认值（10张）；
> 2. **价格管理** — 可自定义修改商品单价，支持重置为默认价格，修改后自动保存至 SD 卡；
> 3. **交易历史** — 查看所有历史交易记录，支持查看详情（商品明细、优惠类型、实付金额）；
> 4. **再来一单** — 在交易明细页面点击"再来一单"，自动将该笔交易的商品和优惠加载到购物车；
> 5. **数据持久化** — 优惠券数量、商品价格、交易记录均保存至 SD 卡，掉电不丢失；
> 6. **SDRAM 大图显示** — 商品图片和主页背景图从 SD 卡加载到 SDRAM，支持 1024×600 高清背景；
> 7. **LED 状态指示** — 通过 4 色 LED（绿/蓝/黄/红）闪烁反馈操作状态（开机自检、操作成功/失败、SD卡读写等）；
> 8. **SDRAM 稳定性测试** — 内置 PRBS（伪随机二进制序列）测试程序，可验证 SDRAM 数据完整性。

## 界面

> 1. **主页** — 4 个功能入口按钮（购物、交易记录、价格管理、优惠券管理），带背景图片；
> 2. **购物界面** — 左侧商品卡片网格（含图片、名称、价格），右侧购物车列表，底部结账/清空按钮，右侧优惠券选择面板；
> 3. **交易历史** — 列表展示历史交易摘要，点击查看明细，支持清空记录和再来一单；
> 4. **优惠券管理** — 显示每种优惠券当前数量，支持加减操作和一键重置；
> 5. **价格管理** — 显示每种商品当前价格，点击可弹出键盘修改，支持重置为默认价格。

## 硬件平台

> - **MCU**：GD32H7XX（ARM Cortex-M7）
> - **显示屏**：1024×600 RGB565 TFT LCD（TLI 接口）
> - **触摸**：电容触摸屏（IIC 接口）
> - **存储**：SD 卡（FATFS 文件系统）
> - **内存**：外挂 SDRAM（4MB+，用于图片缓存和 LVGL 帧缓冲）
> - **LED**：4 色 LED 指示灯（绿/蓝/黄/红）

## 软件架构

```
├── main.c                 # 主入口，系统初始化
├── shop_ui.c              # UI 界面构建与页面管理
├── shop_callbacks.c       # 事件回调（键盘输入、结算、购物车操作）
├── shop_app.h             # 数据结构定义、全局变量声明、函数原型
├── shop_chinese.h         # 中文字符串定义（UTF-8 转义序列）
├── tx_log.c               # 交易记录管理（SD卡读写、CSV解析）
├── read_file_to_array.c   # SD卡文件读取工具函数
├── memory_test.c          # SDRAM PRBS 稳定性测试
├── Hang2Hang.c            # 图片资源数据（LVGL 格式）
├── Drivers/               # 硬件驱动（LCD、触摸、SD卡、SDRAM、LED）
├── FATFS/                 # FatFS 文件系统
├── lvgl/                  # LVGL 图形库
└── GD32H7xx_standard_peripheral/  # GD32 标准外设库
```

## 编译方法

> 1. 下载安装 Keil uVision5，安装 GD32H7xx 器件支持包；
> 2. 准备 GD32H7XX 开发板，连接 LCD、触摸屏、SD 卡；
> 3. 打开 `TemplateProject.uvprojx` 工程文件；
> 4. Rebuild All；
> 5. Download 到开发板。

## 数据存储说明

| 文件 | 路径 | 说明 |
|------|------|------|
| 交易记录 | `0:/transactions.csv` | CSV 格式，包含交易ID、折扣前后总价、优惠类型、商品明细 |
| 优惠券配置 | `0:/coupon.dat` | 4 种优惠券的剩余数量 |
| 价格配置 | `0:/price.dat` | 6 种商品的自定义价格 |
| 商品图片 | `0:/apple.bin` 等 | 200×200 RGB565 格式 |
| 背景图片 | `0:/background.bin` | 1024×600 RGB565 格式 |
